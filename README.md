# Blinkit Grocery Sales Analysis Dashboard
## 📊 Project Overview
This project presents an interactive Blinkit Grocery Sales Analysis Dashboard
developed using Microsoft Excel.
The dashboard provides insights into grocery sales performance based on
item type, outlet type, outlet size, location tier, fat content, ratings,
and other business-related metrics.
The objective of this project is to analyze sales data and identify
important business trends and performance patterns.

## 🎯 Objectives
- Analyze overall grocery sales performance
- Compare sales across different outlet types
- Analyze sales by item type
- Understand sales based on fat content
- Compare sales across location tiers
- Analyze average ratings by outlet size
- Identify yearly sales trends
- Provide KPI-based business insights

## 🛠️ Tools Used
- Microsoft Excel
- Excel Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Dashboard Design

## 📌 Key KPIs
The dashboard includes:
- Total Sales
- Average Sales
- Average Visibility
- Item Count
- Average Rating

## 📈 Dashboard Analysis
The dashboard contains the following visualizations:
1. Sales by Outlet Type
2. Sales by Fat Content
3. Sales by Item Type
4. Sales by Year
5. Sales by Location Tier
6. Average Rating by Outlet Size

## 🎛️ Interactive Filters
The dashboard provides filters/slicers for:
- Item Type
- Rating
- Outlet Type
- Fat Content
These filters allow users to interactively analyze different
segments of the grocery sales data.

## 💡 Key Insights
The dashboard can be used to identify:
- Which outlet types generate higher sales
- Which item categories contribute more to revenue
- Sales differences between low-fat and regular products
- Sales performance across different location tiers
- Year-wise sales trends
- Relationship between outlet size and average rating
